# 📚 FES Library

An online library platform interface featuring curated book highlights, user rating components, and a fully responsive mobile design.

## ✨ Features
* **Fully Responsive:** Adapts seamlessly to Desktop, Tablet, and Mobile screens.
* **Mobile Mobile Menu:** Uses custom JavaScript to toggle an animated full-screen side menu.
* **Interactive UI:** Smooth hover animations on book covers (`transform: scale`) and button click states.
* **Modern Layouts:** Uses clean CSS Flexbox structures and smooth page scrolling mechanics.

## 🛠️ Built With
* HTML5 (Semantic Structure)
* CSS3 (Custom Grid/Flexbox Layouts & Animations)
* JavaScript ES6 (DOM Class Toggles)
* FontAwesome (Icon Assets)

## 📂 Project Structure
* `index.html` - Core semantic page markup.
* `styles.css` - Custom styling layout rules and mobile media queries.
* `script.js` - Open/Close event mechanics for the mobile drawer menu.
* `assets/` - Logo, wave backgrounds, and book cover thumbnail images.

## 🚀 How to Run Locally
1. Clone this repository to your machine.
2. Open the `index.html` file in any standard web browser.
